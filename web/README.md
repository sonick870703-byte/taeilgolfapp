# 태일골프 홈페이지 + ERP (1단계)

아바타ERP를 대신할 태일골프 전용 홈페이지와 직원용 ERP입니다. 하나의 서버가 둘 다 맡습니다.

- `tigc.co.kr` : 고객 홈페이지 (상품, 공지, 회원가입·로그인, 예약 신청, 내 예약)
- `erp.tigc.co.kr` (또는 `tigc.co.kr/erp/`) : 직원 ERP

## 1단계에 들어간 기능

| 영역 | 자동으로 되는 것 |
| --- | --- |
| 예약 | 예약금 20%, 잔금 기한(출발 1개월 전), 환불 기한(출발 14일 전) 자동 계산. 입금을 등록하면 상태(예약금 대기 → 예약금 입금 → 완납)가 자동으로 바뀜 |
| 대시보드 | 새 예약, 입금 대기, 잔금 기한 임박·지남, 출발 D-7, 고객 취소 요청을 "오늘 할 일"로 자동 정리. 월별 출발·매출·미수 자동 집계 |
| 고객 안내 | 예약마다 금액·기한·입금 계좌가 들어간 안내 메시지를 자동 작성 (복사해서 카톡·문자로 보냄) |
| 상품 | 기준가를 넣으면 고객에게는 기준가 + 20,000원이 1인 요금으로 자동 표시. 기준가는 직원만 봄. 한 달 살기 1인 예약은 자동으로 2인 요금 |
| 엑셀로 상품 올리기 | `엑셀 양식 받기`로 받은 양식(분류 선택 목록, 작성 안내 포함)에 한 줄에 상품 하나씩 적어 올리면 상품이 자동으로 만들어짐. 상품코드가 같으면 수정, 새 코드면 새로 등록. 올리기 전 확인 표에서 새로 등록·수정·오류를 미리 보여 줌. 예시 줄(코드가 "예시"로 시작)은 건너뜀 |
| 사진 | 올리면 자리 비율(상품 4:3, 배너 16:7)로 자동으로 잘라내고 큰·중간·작은 크기로 자동 저장 |
| 페이지 만들기 | 틀(회사 소개, 찾아오시는 길, 골프장 안내, 이벤트)을 고르고 블록(제목, 글, 사진, 사진+글, 상품 목록, 버튼, 공지, 상담 안내)을 쌓아 페이지를 만듦. 옆에서 바로 미리보기, 메뉴에 자동 추가. 메인 화면도 같은 방식으로 순서·구성 변경 |
| 홈페이지 설정 | 로고, 색상, 배너, 메뉴 이름, 회사 정보, 입금 계좌, SNS, 약관을 ERP에서 바꾸면 바로 반영 |
| 도메인 연결 | 주소를 넣으면 가비아 등에 넣을 DNS 값을 보여주고, "연결 확인"으로 자동 확인 |
| 회원 | 홈페이지 가입 회원이 ERP에 자동으로 보임. 관리자가 직원 권한을 주면 그 계정으로 ERP 사용 |

개인정보처리방침에는 주민등록번호를 수집 항목으로 넣지 않습니다(법으로 원칙적 금지).

## 실행

Node.js 22.5 이상이면 추가 설치 없이 돌아갑니다. 데이터는 `data/taeil.db` 한 파일(SQLite)과 `data/uploads/` 사진 폴더에 저장됩니다.

```bash
cd web
ADMIN_EMAIL=관리자이메일 ADMIN_PASSWORD='처음비밀번호' node server.js
# 홈페이지 http://localhost:8080  ·  ERP http://localhost:8080/erp/
```

| 환경 변수 | 뜻 |
| --- | --- |
| `PORT` | 포트 (기본 8080) |
| `DATA_DIR` | 데이터 폴더 (기본 `web/data`) |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | 처음 실행할 때 만들 관리자 계정 |
| `ERP_HOSTS` | ERP 화면으로 보낼 주소 (예: `erp.tigc.co.kr`). ERP의 도메인 연결 화면에서 "ERP"로 추가해도 됩니다 |
| `DEMO=1` | 미리보기용 예시 예약을 넣음 |
| `PASSPORT_KEY` | 여권번호 암호화 열쇠 (base64 32바이트). 없으면 `DATA_DIR/passport.key`를 자동으로 만듭니다. **백업할 때 `taeil.db`와 같이 보관하세요.** 열쇠를 잃으면 저장된 여권번호를 읽을 수 없습니다 |

여권 자동 인식: ERP 예약 상세의 "여행자 · 여권"에서 여권 사진을 고르면 `public/vendor/tesseract/`(Tesseract.js, Apache-2.0)로 브라우저 안에서 아래 두 줄(MRZ)을 읽습니다. 사진은 서버로 보내지 않습니다. 여권번호는 AES-256-GCM으로 암호화해 `passports`에 따로 두고, 여행 종료 90일 뒤 자동으로 지웁니다.

서버 없이 `public/` 폴더만 열면(미리보기) 브라우저 안의 데모 저장소로 같은 업무 로직이 돌아갑니다. 미리보기 관리자: `admin@tigc.co.kr` / `demo1234`.

## 사무실 윈도우 PC에 올리기 (무료)

`deploy/windows-setup.bat`을 PC에서 더블클릭하면 `C:\TaeilERP`에 Node.js, 프로그램, Cloudflare 터널을 받고, 로그인할 때 자동으로 켜지게 등록합니다. 관리자 권한은 필요 없습니다. 직원 공유 주소(`*.trycloudflare.com`)는 PC를 다시 켤 때마다 바뀌며 `C:\TaeilERP\접속주소.txt`에 적힙니다. 고정 주소(erp.tigc.co.kr)는 Cloudflare 계정으로 이름 있는 터널을 만들어 붙입니다. 다시 실행하면 데이터는 두고 프로그램만 최신으로 바꿉니다. 프로그램 파일을 바꾸면 `deploy/make-manifest.sh`로 목록을 갱신하세요.

## 오라클 클라우드 무료 서버에 올리기

Ubuntu 서버에 접속해서 한 줄을 붙여 넣으면 Node.js, 자동 https(Caddy), 자동 시작까지 설치됩니다.

```bash
curl -fsSL https://raw.githubusercontent.com/sonick870703-byte/taeilgolfapp/claude/project-thread-8bxa3u/web/deploy/oracle-setup.sh | sudo bash
# 주소를 붙일 때: ... | sudo SITE_DOMAIN=new.tigc.co.kr ERP_DOMAIN=erp.tigc.co.kr bash
```

처음 관리자 비밀번호는 설치 끝에 한 번 보여 주고 서버의 `/etc/taeil.env`에만 저장합니다. 오라클 콘솔의 보안 목록(Security List)에서 TCP 80, 443을 열어야 합니다.

## 항공권 (홈페이지 `#/flights`, ERP `항공권`)

- 키가 없을 때: 고객은 날짜·인원으로 **견적 요청** → ERP에서 요금과 항공편 내용을 넣으면 고객 "내 항공권"에 결제 버튼이 생김 (계좌 입금 확인도 가능).
- Duffel 토큰을 넣으면: 실시간 요금 검색(같은 조건 10분 캐시, 1분 30회 제한) → 탑승객 입력 → 요금 재확인 → 카드 결제 → 발권(자동 또는 직원 버튼). 좌석을 잡아 둘 수 있는 항공편은 결제 전 hold 주문을 만들어 둠.
- 토스페이먼츠 키를 넣으면 카드 결제(`flights-pay.html`에서 서버가 금액 확인 후 승인), ERP에서 카드 취소.
- 키는 ERP `항공권 → 연결 설정`(관리자)에 넣고 `secrets` 컬렉션에 저장되며 `/api/site`로 나가지 않음.
- 판매가 = 원가 × 환율 × (1 + 환율 여유%) + 1인 수수료 × 인원 (100원 올림). 환율은 비우면 open.er-api.com에서 6시간마다.
- 미리보기(서버 없음)에서는 "예시 요금 (실제 요금 아님)"만 보이고 예약은 막힘.
- 파일: `shared/flights.js`(API), `shared/flights-site.js`, `shared/flights.css`, `flights-pay.html`, `erp/flights.js`.
